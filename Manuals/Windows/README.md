# Apollo Reader — Windows Manual

## Installation

Apollo Reader is available exclusively through the **Microsoft Store** on Windows.

To install Apollo Reader:

1. Open the **Microsoft Store** on your Windows PC.
2. Search for **Apollo Reader**.
3. Select Apollo Reader from the search results.
4. Click **Install**.
5. Once installation is complete, click **Open**, or launch Apollo Reader later from the Windows Start menu.

Updates to Apollo Reader are also distributed through the Microsoft Store and will normally be installed automatically along with your other Store apps.

## Adding your library

Apollo Reader organizes comics into libraries. Each library can contain one or more folders and can have its own default reading settings.

To add a library:

1. Select **Libraries** from the left sidebar.
2. Open the **Manage** tab.
3. Click **Add library**.
4. Enter a name for the library.
5. Click **Add folder** and select the folder that contains your comics.
6. To include additional folders in the same library, click **Add folder** again and repeat the process.

You can also choose the default reading settings for the library:

* **Reading direction** — Sets the default direction used when navigating through comics in this library.
* **Page fit mode** — Controls how pages are initially sized in the reader.

  * **Fit Height** — Fits the page vertically to the available reader area. This is the default and is generally the best option for standard comic books.
  * **Fit Page** — Displays the entire page within the available reader area.
  * **Fit Width** — Fits the page to the width of the reader.

### Scrub titles

Enable **Scrub titles** if you want Apollo Reader to clean up comic filenames when displaying them in your library.

When enabled, Apollo Reader attempts to remove extra filename information while preserving the important parts of the title, such as the **series name**, **issue number**, and **year**.

Once your folders and library defaults are configured, click **Add Library** to create the library.

## The Cover Grid

To browse your comics, select **Libraries** from the left sidebar, then open the **Libraries** tab.

Choose the library you want to view. Apollo Reader will display the contents of that library as a visual cover grid containing both folders and comic books.

### Books

Each comic book is displayed using its cover image.

Cover images are generated automatically as you browse through your library, so covers may appear progressively the first time you view a folder or library.

Select a book to open it in the reader.

### Folders

Folders are displayed using a collage made from several comic covers contained within that folder.

Select a folder to open it and browse the books and subfolders inside.

This allows larger collections to retain their existing folder organization while still providing a visual way to browse your comics.

### Search

Use the search bar at the top of the library view to find comics by title.

Search is global and searches across **all comics in all of your libraries**, regardless of which library you are currently viewing.

## Reading a comic

Select any comic from the cover grid to open it in the Apollo Reader.

### Reader controls

While reading, the main controls are contained in a hidden toolbar at the top of the screen.

* With a mouse, move the pointer to the top of the reader to reveal the toolbar.
* On a touchscreen, tap near the top of the reader.

The toolbar includes:

* **Back** — Returns to the previous screen.
* **Go to folder** — Returns directly to the folder containing the current comic.
* **Comic title** — Displays the title of the comic currently being read.
* **Page navigation** — Displays the current page and total number of pages, with controls to move backward or forward.
* **Full screen** — Switches the reader into or out of full-screen mode.
* **Settings** — Opens the reader settings for the current reading session.

### Reader settings

Select the **gear icon** to adjust how the current comic is displayed and navigated.

Available options include:

* **Reading Mode**

  * **Single Page** — Displays one page at a time.
  * **2 Page Spread** — Displays two pages side by side.

* **Page Fit**

  * Controls how comic pages are fitted within the reader window.

* **Direction**

  * Sets the reading direction used for page navigation.

* **Page Transition**

  * **Slide** — Pages animate into view when changing pages.
  * **Instant** — Pages change immediately without an animation.

* **Pre-cache Pages**

  * Controls how many upcoming pages Apollo Reader prepares in advance.
  * The default is **3 pages**.

* **Page Number Display**

  * Controls how long the page-number pop-up remains visible after changing pages.
  * **Short** — The default setting.
  * **Hidden** — Does not display the page-number pop-up.
  * **Long** — Keeps the page-number pop-up visible for longer.

These settings apply to the current reading session.

### Turning pages

When using the default **left-to-right** reading direction:

* Click or tap the **right side** of the page to move forward.
* Click or tap the **left side** of the page to move backward.

On a touchscreen, you can also swipe horizontally. Swiping far enough in the appropriate direction will turn the page.

When the reading direction is changed, the forward and backward navigation sides are reversed accordingly.

## Reading modes and navigation

Apollo Reader supports multiple ways to view and navigate book pages using a mouse, trackpad, or touchscreen.

### Page fit

The **Page Fit** setting controls how pages are sized within the reader.

Available options include:

* **Fit Height** — Fits the page to the height of the reader. This is the default and works well for most standard books.
* **Fit Page** — Fits the entire page within the available reader area.
* **Fit Width** — Fits the page to the width of the reader.

### Reading mode

Apollo Reader can display books in either:

* **Single Page** — Displays one page at a time.
* **2 Page Spread** — Displays two pages side by side.

You can switch between these modes at any time using the reader settings.

### Reading direction

The **Direction** setting controls which side of the reader advances to the next page.

This can be changed at any time from the reader settings to support both left-to-right and right-to-left books.

### Zooming

You can zoom in on a page for a closer look at artwork or text.

**Mouse**

* Use the **mouse wheel** to zoom in or out.

**Trackpad**

* Use a **pinch gesture** to zoom in or out.

**Touchscreen**

* Place two fingers on the page and **pinch inward or outward** to adjust the zoom level.

### Panning

When a page is zoomed in, you can move around the page to view different areas.

**Mouse**

* Click and drag the page to pan.

**Touchscreen**

* Touch and drag the page to pan.

## Recent history

Select **Recent** from the left sidebar to view books you have opened recently.

By default, Apollo Reader displays recent history using the **By Library** view. You can switch between three tabs:

* **By Library**
* **By Date**
* **All Recent**

A search bar is available at the top of the Recent view. Search follows the currently selected tab, so results remain organized using that view.

### By Library

The **By Library** view groups recent books under the library they belong to.

Each library has its own header followed by the recent books from that library.

* Click the **chevron to the left** of a library name to collapse or expand it.
* Use the **up and down chevrons to the right** of the library name to change the order in which libraries appear.
* Select any book to open it in the reader.

This lets you keep the libraries you use most frequently near the top of your recent history.

### By Date

The **By Date** view organizes recently opened books into time-based groups:

* **Today**
* **This Month**
* **All Time**

Select any book to open it in the reader.

### All Recent

The **All Recent** view displays your recent books as a single list without grouping them by library or date.

### Searching recent history

Use the search bar to filter your recent books.

Search respects the currently selected tab:

* In **By Library**, results remain grouped by library.
* In **By Date**, results remain grouped by date.
* In **All Recent**, results are displayed as a single list.

## Settings

Select **Settings** from the left sidebar to configure Apollo Reader’s default behavior and manage cached data.

### Theme

Choose the application theme used by Apollo Reader.

### Default Page Fit

Sets the default page fitting mode used when opening books.

Available options include:

* **Fit Height** — Fits the page to the height of the reader.
* **Fit Page** — Fits the entire page within the available reader area.
* **Fit Width** — Fits the page to the width of the reader.

Individual libraries can have their own page-fit defaults, and the setting can also be changed while reading.

### Default Reading Direction

Sets the default reading direction for books.

This determines which side of the reader advances to the next page.

Individual libraries can override this default.

### Pre-cache Pages

Controls how many pages Apollo Reader prepares ahead of and behind your current page.

The default is **3 pages**.

Increasing this value can make page turning feel more immediate, but will use more memory. Set it to **0** to disable page pre-caching.

### Page Number Display

Controls how long the page-number indicator remains visible after turning a page.

The default is **Short**.

Available options include:

* **Hidden**
* **Short**
* **Long**

### Cover Cache Limit

Apollo Reader stores generated cover images in a local cache so they do not need to be regenerated every time you browse your library.

The **Cover Cache Limit** controls the maximum amount of disk space the cover cache can use.

* Enter a limit in **MB**.
* Set the value to **0** for an unlimited cache.

The current size of the cover cache is displayed below this setting.

### Skip covers for large PDF files

When enabled, Apollo Reader will avoid generating cover images for particularly large PDF files.

This option is enabled by default because generating covers for large PDFs can require a significant amount of memory.

Disable it only if you want covers generated for these files and your device has sufficient available memory.

### Clear Cover Cache

Click **Clear Cover Cache** to delete all generated cover images.

Apollo Reader will regenerate covers automatically as you browse your libraries again.

Clearing the cache does not remove your books, libraries, or reading progress.

### Saving settings

Click **Save** after making changes to apply your settings.

### Danger Zone

The **Danger Zone** contains the option to reset Apollo Reader’s local database.

Resetting the database deletes Apollo Reader’s stored application data, including:

* Libraries
* Reading progress and history
* Cached data

Your original book files are not deleted.

After the database is reset, Apollo Reader will restart and you will need to add your libraries again.

Use **Delete Database** only when you intentionally want to reset Apollo Reader to a fresh state.

## Troubleshooting

If Apollo Reader is not behaving as expected, try the steps below before resetting the application.

### A book will not open

First, make sure the original book file is still available in the folder that was added to Apollo Reader.

If the book is stored on an external drive, network location, or other removable storage, make sure that location is currently accessible.

If the file has been moved, renamed, or deleted outside Apollo Reader, the library may still contain information from the previous location.

### Covers are missing or incorrect

Apollo Reader generates and caches cover images as you browse your libraries.

If a cover does not appear correctly:

1. Open **Settings**.
2. Click **Clear Cover Cache**.
3. Return to your library and browse to the affected books.

Apollo Reader will regenerate the covers as they are needed.

For very large PDF files, cover generation may be skipped if **Skip covers for large PDF files** is enabled.

### Apollo Reader is using too much memory

Page pre-caching and cover generation both use memory.

If Apollo Reader is using more memory than expected:

* Reduce **Pre-cache Pages** in Settings.
* Leave **Skip covers for large PDF files** enabled.
* Close and reopen Apollo Reader after working with particularly large books.

### A setting or reader behavior seems stuck

Close Apollo Reader completely and open it again.

If the problem affects only a particular reading session, reopen the book and check the reader settings from the **gear icon**.

Also check whether the library has its own defaults for **Page Fit** or **Reading Direction**, as library settings can override the application defaults.

### Apollo Reader will not start

Restart Windows and try launching Apollo Reader again.

If it still will not start, uninstall Apollo Reader and install it again from the **Microsoft Store**.

Depending on the problem, reinstalling the application may require you to add your libraries again.

### Resetting Apollo Reader

If Apollo Reader starts but its library or application data appears to be damaged, you can perform a complete database reset.

Open **Settings**, scroll to the **Danger Zone**, and select **Delete Database**.

This removes Apollo Reader's stored data, including:

* Libraries
* Reading progress and history
* Cached data

Your original book files are **not deleted**.

Apollo Reader will restart after the reset. You can then add your libraries again.

Use this option only after other troubleshooting steps have failed.
